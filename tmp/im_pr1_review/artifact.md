# Контракт оформления

Титульный образец: D:/GitHub/MIREA/4/ИСУРО/ИСУРО_1_АлбахтинИВ.docx.
Используются только первые 16 элементов body, завершающиеся абзацем «Москва 2026 г.» с разрывом раздела. Сохраняются университетская таблица, эмблема, двойная линия, институт, кафедра, подписи и положение города. Меняются вид работы, предмет, преподаватель, удаляется старая группа. Шрифтовые подстановки нормализуются в Times New Roman. Основная часть образца не используется.

Основная часть: исходный ИМ, общие параметры из Оформление_отчётов.md. А4, поля 3/1,5/2/2 см, TNR 14, 1,5, первая строка 1,25 см. Таблицы TNR 12, 1,0; подписи таблиц курсив 12 слева, рисунков 14 по центру. Заголовки 14 полужирные; основные по центру, подразделы слева. Нумерация снизу по центру, титульник без номера.

Оргструктура: неизменённое встроенное изображение из абзаца 55 ППОИС_1_АлбахтинИВ.docx. Для читаемости отдельная альбомная страница. Сохраняются все её подразделения и связи. Текст ответственности согласуется с изображением. Вторая схема функций исключается как не требуемая методичкой. Служебные пояснения и комментарии Word исключаются.

Проверка: штатный render_docx.py не нашёл LibreOffice. Конверсия DOCX в PDF выполняется установленным Word через COM; rasterize из render_docx.py и bundled Poppler формируют страницы для визуальной проверки.
