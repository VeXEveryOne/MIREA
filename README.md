В каждой работе хранить один актуальный комплект DOCX/PDF, редактируемые модели и необходимые исходные данные. PDF и DOCX являются разными форматами сдачи; исходники и готовые результаты также имеют отдельное назначение. Общие библиотеки, виртуальные окружения, временные сборки, блокировки Office и промежуточные проверки в Git не добавлять. Для новых сборок использовать `.cache/`, а для локальных зависимостей — окружение соответствующего проекта.

Два проекта Playlist Maker сохранены как подмодули: [основной проект](playlist-maker-android-AlbahtinIlya/) и [версия курса](ya/playlist-maker-android-AlbahtinIlya/). Они находятся на разных коммитах и сохраняют разные этапы работы. После клонирования их можно получить командой `git submodule update --init --recursive`.

Результаты очистки и правила восстановления: [рефакторинг от 04.10.2026](docs/Рефакторинг_2026-10-04.md).
