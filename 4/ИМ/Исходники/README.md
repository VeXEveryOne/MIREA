# Генераторы моделей ИМ

Здесь сохранены генераторы актуальных моделей, ранее находившиеся во временной папке. Готовые проекты хранятся в `../OmniNotation/`; отчёт и PDF остаются в каталоге предмета.

`build_idef0.mts` создаёт AS IS и TO BE; `build_report_uml.mts` — модели UML; `build_gantt.mts` — календарный план. `prepare_term_clean_models.mts` приводит терминологию импортированных примеров к модельному ряду.

Запуск из корня MIREA: `node <OMNINOTATION_ROOT>/node_modules/tsx/dist/cli.mjs 4/ИМ/Исходники/имя_скрипта.mts` с фактическим именем скрипта. Переменная `OMNINOTATION_ROOT` настраивает внешний репозиторий; `IM_MODEL_OUTPUT` позволяет направить пробную сборку в отдельный каталог. Исходники OmniNotation являются внешней зависимостью и не копируются в MIREA.

После обновления моделей повторно экспортировать рисунки, проверить их в отчёте и затем пересобрать PDF. Сам запуск генератора не изменяет готовый DOCX.
