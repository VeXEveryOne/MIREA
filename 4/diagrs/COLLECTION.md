# Коллекция диаграмм OmniNotation

Перенесена из D:/OmniNotation 08.10.2026. Файлы .omni открываются в приложении через «Открыть» либо проводник рабочей папки. Каталог im и сопутствующий SQL сохранены. Хеши оригиналов находятся в transfer-manifest.json.

_authoring содержит архив прежних предметных фабрик, генераторов и учебных фрагментов. Их импорты соответствуют прежним путям репозитория; это архив происхождения, а не автономный исполняемый проект.
