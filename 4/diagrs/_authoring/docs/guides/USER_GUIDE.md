# Общие приёмы ручного редактора

Это руководство объясняет действия, одинаковые для нотаций OmniNotation. После него откройте инструкцию своей нотации: там описаны смысл элементов и специальные команды. Работать можно мышью и через свойства.

Кнопка **«Помощь»** открывает эти же документы без интернета. При открытой схеме сначала показывается её нотация. Выберите руководство в списке, используйте содержание или поиск внутри руководства. Поиск оставляет разделы, содержащие все введённые слова; «Сбросить поиск» возвращает полный текст. Escape закрывает помощь.

## Создать, открыть и сохранить

1. Нажмите **«Создать»**. Выберите семейство и доступный шаблон. Заготовка подходит для своей схемы; готовые документы открывайте из отдельной коллекции. WIP означает, что редактор вида ещё не реализован.
2. Назовите документ: двойной щелчок по имени вкладки, введите имя, Enter. Escape отменяет. Имя документа и названия элементов независимы.
3. Создайте элементы и связи по инструкции нотации. Свойства выделенного элемента находятся справа; проводник и поиск — слева.
4. Нажмите **«Сохранить»** или Ctrl+S. При первом сохранении выберите папку и имя. Новый файл имеет расширение `.omni`. Ctrl+Shift+S сохраняет под другим именем.
5. Для открытия используйте Ctrl+O, домашний экран или проводник. Рабочая папка выбирается кнопкой `▱＋`; `↻` перечитывает её после внешних изменений.

Переносимая сборка запускается из своей папки целиком: один EXE без соседних файлов переносить нельзя. Открытие с диска, сохранение и запись экспорта доступны в настольном приложении. Моделирование и справка работают без интернета.

Файл хранит модель, собственный исходный текст, непринятый черновик и расположение. Старые `.nsdfd`, `.nsidef0`, `.nsuml`, `.nsbpmn` читаются для миграции; новые файлы сохраняются как `.omni`. Вкладки и черновики восстанавливаются после перезапуска, история отмены — только в текущем сеансе. Восстановление сеанса не заменяет сохранение файла.

## Организовать рабочее пространство

Вкладки переключаются щелчком или Ctrl+Tab / Ctrl+Shift+Tab и переставляются перетаскиванием. Крестик, средняя кнопка или Ctrl+W закрывают вкладку. При несохранённых изменениях приложение предлагает сохранить их. Повторное открытие того же пути активирует открытую вкладку.

Потяните разделитель у проводника, свойств или над кодом, чтобы оставить больше места полотну. Двойной щелчок возвращает размер панели. Сфокусированный через Tab разделитель реагирует на стрелки, Shift+стрелки и Home/End; Escape отменяет перетаскивание. Размеры запоминаются по нотациям и не меняют размер схемы.

Код и диагностику можно свернуть. Миникарта по умолчанию выключена; её включает кнопка навигации справа снизу. На небольшой схеме оставьте её выключенной. На узком окне строка команд прокручивается горизонтально. Нажатие на логотип переключает светлую и тёмную темы.

## Выделять, двигать и переименовывать

| Действие | Приём |
| --- | --- |
| Выбрать элемент, показать свойства | Один щелчок |
| Выбрать несколько | Ctrl+щелчок; рамка Ctrl+перетаскиванием по пустому фону |
| Двигать элемент | Перетащить фигуру |
| Двигать полотно | Перетащить пустой фон; также средняя или правая кнопка |
| Изменить масштаб | Колесо или кнопки навигации |
| Увидеть схему целиком | «Вписать» или кнопка навигации |
| Найти элемент | Ctrl+F переводит фокус в поиск проводника; щелчок по результату показывает элемент |
| Изменить подпись | F2 или двойной щелчок; специальные встроенные таблицы описаны в нотационных инструкциях |

Обычное поле принимает изменение по Enter или при выходе из поля. Escape отменяет; многострочные поля допускают Shift+Enter. В форме с отдельной кнопкой **«Применить»** завершите всю форму этой кнопкой. Если действие отклонено, прочитайте строку состояния и диагностику.

Название — видимая подпись. ID — устойчивая ссылка для связей, частей и листов. Для изменения ID используйте **«Переименовать ID…»**, если команда есть в свойствах: она показывает затронутые ссылки. F2 не меняет ID. Пустые/повторяющиеся ID недопустимы.

Статические подписи интерфейса не выделяются как текст. Ctrl+A вне текстового поля не выбирает ни интерфейс, ни все фигуры. В поле ввода/переименования и редакторе кода он выделяет только редактируемый текст. На macOS заменяйте Ctrl основных команд на Cmd.

## Добавлять элементы и связи

Палитра показывает элементы активной нотации и вида листа. В DFD, BPMN и IDEF0 кнопки могут добавлять элемент сразу. В редакторах с декларациями выбор фигуры включает размещение: затем щёлкните по полотну или перетащите кнопку из палитры, заполните форму и нажмите «Создать». Escape отменяет размещение. Мастера частей открываются кнопками со знаком `…`.

Связь создаётся протягиванием между допустимыми точками либо через мастер в палитре/свойствах. Вид связи и концы зависят от нотации. Назовите связь, если подпись помогает понять данные, условие или взаимодействие.

В редакторах деклараций подпись связи перемещается отдельно. На выбранной связи двойной щелчок добавляет изгиб; переместите маркер, двойной щелчок по маркеру удаляет его. Escape отменяет жест. У DFD, IDEF0 и специальных UML-связей свои маркеры маршрутов.

## Модель и отображение на листе

В UML, ERD и редакторах с несколькими листами один объект может иметь несколько отображений. Одна таблица присутствует на концептуальном и физическом листах, один артефакт — на двух серверах.

- **«Показать на листе»** использует имеющееся отображение или добавляет отсутствующее. Выберите объект в списке палитры или перетащите из проводника.
- **«Ещё одно отображение»** создаёт дополнительную фигуру того же объекта там, где вид листа это допускает.
- **Delete / «Убрать только с листа»** в таких редакторах убирает отображение. Объект остаётся в модели.
- **«Удалить из модели…»** показывает зависимые объекты и отображения. Просмотрите список: удаление владельца может затронуть части и связи.

В DFD, BPMN и IDEF0 удаление удаляет сам объект и зависимые связи; отдельное скрытие отображения не является общей командой Delete. Undo возвращает принятую операцию.

Наложение фигур само по себе не задаёт владельца. Используйте поле владельца, специальные команды или явно включённый режим Drop с предпросмотром. Геометрическая группа перемещает фигуры вместе, но не меняет подчинение.

## Копировать, отменять и оформлять

Ctrl+C копирует выделение во внутренний буфер схем, Ctrl+V вставляет в документ той же нотации, Ctrl+D дублирует. Части, внутренние ссылки и оформление переносятся с новыми ID. Между документами может открыться просмотр зависимостей; проверьте его. Несовместимая внешняя ссылка отклоняет операцию целиком.

Ctrl+Z отменяет, Ctrl+Y или Ctrl+Shift+Z повторяет. На macOS повтор — Cmd+Shift+Z, удаление — Backspace. Отмена включает модель и расположение. Выделение, обзор и поиск не меняют смысл схемы.

**«Геометрия…»**, если доступна, выравнивает фигуры по краям/центрам, распределяет промежутки и раскладывает в строку, столбец или сетку. Для выравнивания нужны две фигуры, для промежутков — три. Закрепление исключает фигуру из автоматической раскладки. Кнопка `#` переключает сетку в поддерживающих её редакторах. Цвет, размер текста, видимые строки и маршруты задаются у отображения и не меняют тип объекта.

## Код, ошибки и готовность

Нижняя панель редактирует ту же модель собственным языком: `тип id название ключ=значение`, один элемент на строку, многословные/пустые значения в двойных кавычках. Подсказки Ctrl+Space относятся к текущей нотации. Для ручного построения панель можно свернуть.

Корректный текст синхронизируется со схемой. При ошибке сохраняются черновик и последняя принятая модель; частичного применения нет. Пока черновик не принят, визуальные команды могут быть заблокированы. Исправьте диагностику и нажмите **«Применить код»** либо **«Вернуть корректный код»**, если отказываетесь от черновика. Сохранение сохраняет и черновик.

В верхнем меню `⋯` выберите **«Проверить готовность»**. Диалог объясняет замечания и позволяет перейти к объекту. Ошибка ссылки/владельца обычно блокирует изменение; замечание о незавершённости позволяет продолжать, сохранять и экспортировать. Готовность относится к реализованному профилю, а не к сертификации полного стандарта.

## Экспортировать результат

1. Нажмите **«Экспорт»**. Выберите текущий лист, выделение, проект, открытые документы или список листов.
2. Выберите PNG или PDF. PNG принимает пиксели либо физическую ширину в мм при 300 dpi. Для PDF доступны A4/A3, ориентация, поля, вписывание и постер по нескольким страницам.
3. Посмотрите предпросмотр и замечания. Вписывание большой схемы удобно для обзора; для чтения увеличьте физический размер или используйте постер.
4. При необходимости включите скрытые элементы/полное раскрытие. Это выполняется в экспортной копии и не меняет рабочий лист.
5. Выберите место записи. При конфликте имён добавляется числовой суффикс. Отмена прекращает дальнейший вывод после текущей операции; отчёт показывает записанные файлы и ошибки.

Экспорт использует принятую модель, а не ошибочный черновик. Панели, выделение и временные значения прототипа не входят в результат. PDF создаётся Chromium; некоторые эффекты могут быть растровыми. PNG/PDF не заменяют редактируемый `.omni`.

## Если действие не получается

| Симптом | Что проверить |
| --- | --- |
| Палитра/свойства недоступны | Непринятый черновик, открытый диалог, режим прототипа |
| Не создаётся связь | Тип связи/концов, направление, владельца и отображения обоих концов |
| После Delete объект остаётся в проводнике | Убрано отображение; для полного удаления нужна другая команда |
| Объект не виден | Активный лист, отображение, свёрнутого родителя, «Вписать» |
| Внешний вид изменился, смысл прежний | Изменено отображение; владелец задаётся отдельно |
| Сохранение удерживается | Завершите встроенную форму применением или Escape |
| Схема не готова | Откройте проверку, завершите отмеченные части; рабочий файл можно сохранить |

Одинаковые жесты не делают одинаковыми правила нотаций. Для смысловых ошибок продолжите в инструкции своей нотации.
