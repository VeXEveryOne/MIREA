При обычном повторе не задавать `TIABD_CAPTURE=1`: эта опция ставит ноутбуки
на паузу для сохранения живого Spark UI. Для работы в интерфейсе открыть JupyterLab,
ввести локальный токен из `Доступ.txt` и выбрать ноутбук в каталоге `АлбахтинИВ`.

Для пересборки DOCX на Windows выполнить `Исходники/build_reports.py`, затем
`Исходники/build_extra_reports.py`. Отдельные части ПР2 будут обновлены в
[исходниках сборки](Исходники/Компоненты_ПР2/). Для обновления только ПР2 Албахтина запустить `Исходники/build_pr2_storage_report.py`,
затем из `4/BD` — `scripts/prepare_combined_pr2.py --student АлбахтинИВ` и
`scripts/build_combined_pr2.ps1 -Students АлбахтинИВ`. Оглавление обновляется,
раздел визуализации сохраняется. Временные рендеры хранить в `.cache/`.

Только ПР3 пересобирается через `Исходники/build_pr3_report.py`.
Только ПР4 — через `Исходники/build_pr4_report.py`; сборщик требует успешного
Run All и независимой проверки данных. Полный повтор ПР4 с автоматическими
снимками живого UI, без ожидания ручного подтверждения:

