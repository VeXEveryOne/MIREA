## Данные и окружение

[source_manifest.json](source_manifest.json) фиксирует точные исходники.
UCI Online Shoppers и Seoul Bike распространяются на условиях CC BY 4.0;
пользовательские CSV остаются в локальном `data/` и VM. Подготовка на Windows:

```powershell
python prepare_data.py --downloads 'C:\Users\VeX\Downloads\5'
```

Скрипт получает два официальных архива UCI, распаковывает предоставленные Dry
Bean и Podcast, копирует Calories и проверяет SHA256 каждого CSV. Входные CSV
не редактируются. Каталоги `data/`, `models/` и временные Spark Parquet в `work/`
не добавляются в Git.

Проверенное окружение Ubuntu VM: Python 3.10.12, Java 17, Spark 3.5.7,
2 vCPU и 4 ГБ RAM. Зависимости зафиксированы в
[requirements-ml.txt](requirements-ml.txt). Для Spark нужен JDK; для ПР6 и ПР7
Spark не используется. Построение полного дерева Ward требует памяти порядка
квадрата числа объектов; здесь использованы все строки без уменьшения набора.

## Полный повтор

В существующей учебной VM:

```bash
cd /home/albakhtin/tiabd/АлбахтинИВ/ML
/home/albakhtin/tiabd/.venv/bin/python run_notebook.py 5
/home/albakhtin/tiabd/.venv/bin/python run_notebook.py 6
/home/albakhtin/tiabd/.venv/bin/python run_notebook.py 7
/home/albakhtin/tiabd/.venv/bin/python verify_results.py
```

[run_notebook.py](run_notebook.py) очищает старые выходы, запускает свежее ядро,
проверяет все последовательные execution_count и отсутствие ошибок. Запуски
нужно выполнять последовательно в пределах ресурсов VM.
[verify_results.py](verify_results.py) заново сопоставляет прогнозы с исходными
строками и частями, пересчитывает метрики NumPy/scikit-learn, силуэты и срез
дерева. Среднее train и медианы предобработки проверяются по исходным данным.

Источники блокнотов: [build_pr5_notebook.py](build_pr5_notebook.py) извлекает
все 20 блоков кода из канонической методички и добавляет самостоятельную часть
[pr5_independent.py](pr5_independent.py); [build_notebooks.py](build_notebooks.py)
создаёт ПР6/7 из [practice6.py](practice6.py) и [practice7.py](practice7.py).
Перегенерация очищает выходы, поэтому после неё обязателен новый Run All.

## ПР7 в Colab

Методичка прямо требует ColabNotebook. Блокнот подготовлен для этой среды:
открыть `.ipynb`, загрузить `podcast_dataset.csv` в рабочий каталог либо `data/`,
перезапустить runtime и выполнить Run All. Используется CPU; платный GPU не нужен.
Показатель `environment.google_colab` в `summary.json` различает фактическую
среду выполнения. Сохранённые исходные замеры относятся к VM; облачный запуск
должен иметь собственное подтверждение, чтобы не смешивать времена разных CPU.

Одинаковый набор в учебной группе проверяется по реестру группы. Доступный
личный комплект использует разные самостоятельные наборы для ПР5, ПР6 и ПР7.
