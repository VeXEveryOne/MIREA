# KNIME и анализ больших данных

[Презентация](KNIME_Big_Data_RU.pptx) и [текст выступления](KNIME_Big_Data_RU_script.md) хранятся здесь в единственном экземпляре.

`Исходники/build-deck.mjs` — генератор презентации; `Исходники/assets/` — использованные изображения. `download-assets.ps1` повторно загружает исходные изображения при необходимости. Промежуточные файлы сборки создаются в `.cache/knime-presentation/` в корне MIREA.

Генератор использует комплектную библиотеку `@oai/artifact-tool` и общий модуль [tools/runtime.mjs](../../../tools/runtime.mjs). Установка зависимостей внутри каталога отчёта не нужна.
