# Практические работы по анализу больших данных

Каталог разделён по работам:

- [Практическая работа №1](practice_1/README.md) — Pandas, NumPy, EDA и форматы хранения.
- [Практическая работа №2](practice_2/README.md) — Matplotlib, Plotly, t-SNE и UMAP.

Подробные ответы на контрольные вопросы лекций в формате практик:

- [Лекция №1](Лекция_1_Контрольные_вопросы.md) — Big Data, архитектуры, масштабирование, ETL/ELT; 8 вопросов.
- [Лекция №2](Лекция_2_Контрольные_вопросы.md) — SQL, оконные функции, планы запросов и NoSQL; 8 вопросов.

Общее Python-окружение находится в `.venv`, зависимости перечислены в
`requirements.in` и `requirements.txt`. Команда `run_all.cmd` повторно выполняет
ноутбуки обеих работ, а `start_jupyter.cmd` запускает Jupyter из корня каталога.

## Запуск в VS Code

Откройте в VS Code именно каталог `D:\GitHub\MIREA\4\BD`. Проект уже настроен
на интерпретатор `.venv\Scripts\python.exe`. Для ноутбука выберите ядро
`Python (BD - VS Code)`. Полную пересборку второй работы можно запустить через
`Terminal → Run Build Task` или сочетанием `Ctrl+Shift+B`.

Итоговые DOCX и PDF находятся внутри соответствующих папок `practice_1` и
`practice_2`. Исходное задание второй работы сохранено в `practice_2/assignment`.

После переоформления отчётов прежний `practice_2/scripts/build_report.py`
останавливается на проверке контрольной суммы первой практики. Перед следующей

замена контрольной суммы вернёт прежние стили и уберёт титульник. Запуск самих
ноутбуков от оформления DOCX не зависит.
