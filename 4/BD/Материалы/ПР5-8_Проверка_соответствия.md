## Практика 5

Актуальное основание: условия Moodle, предоставленные пользователем 08.11.2026.
Повторять демонстрационный код не требуется. Выбран один самостоятельный набор
Calories, 15 000 строк; все три задачи выполнены в PySpark.

| Требование | Выполнение и доказательство |
| --- | --- |
| Свой набор | Предоставленный calories.csv; SHA256, явная схема, уникальность 15 000 ключей, NULL и диапазоны проверены |
| Регрессия | LR/RF, четыре настройки, выбор по RMSE valid, baseline среднего train, итоговые RMSE/MAE/R² на test |
| Классификация | Calories >= 200, LR/RF, четыре настройки по PR-AUC valid, 17 вероятностных порогов по F1 valid, матрица и ROC/PR-AUC test |
| Кластеризация | Шесть числовых признаков без цели и ключа; все 15 000 строк; k=2…8, одна выборка 2 000 строк для силуэта squaredEuclidean, профили и PCA |
| Pipeline | Все обучаемые преобразования прогнозных задач fit только на train; три сохранённые PipelineModel, после load расхождения 0 |
| Сдаваемые материалы | [Выполненный notebook](../АлбахтинИВ/ML/Practice_5.ipynb) и [прямой PDF-экспорт](../АлбахтинИВ/ML/Practice_5.pdf), титульник, содержание, ФИО, группа, дата 08.11.2026 |

Полный Run All: 10 кодовых ячеек с номерами 1–10, ошибок 0, четыре встроенных
графика. [Протокол](../АлбахтинИВ/ML/results/pr5/execution.json) фиксирует SHA256.
[Независимая проверка](../АлбахтинИВ/ML/results/pr5/verification.json) восстановила
части 9 000/3 000/3 000, сверила цели, пересчитала все тестовые метрики, четыре
классификатора valid, сетку 17 порогов и семь силуэтов. Профили покрывают все
15 000 тренировок. [Проверка сдаваемого комплекта](../АлбахтинИВ/ML/results/pr5/submission.json).
Старые демонстрационные результаты удалены из актуального комплекта;
исходная демонстрация остаётся в методичке.

| Пункт | Выполнение |
| --- | --- |
| Данные и нормализация | Dry Bean, все 13 611 объектов и 16 числовых признаков, StandardScaler; Class исключена из входа |

| Визуализация | t-SNE всех строк, одна проекция для трёх разбиений; силуэт считается в исходном стандартизованном пространстве |
| Отчёт и выводы | Профили, сравнение силуэта и покрытия, ARI/NMI только после подбора, ограничения интерпретации |

[Notebook](../АлбахтинИВ/ML/Practice_6.ipynb): 6 кодовых ячеек подряд, ошибок 0,
