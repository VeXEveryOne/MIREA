## Повторный запуск

Открыть в VS Code каталог `4/BD`; настройки проекта указывают на `.venv/Scripts/python.exe`. Установить зависимости командой `./.venv/Scripts/python.exe -m pip install -r scripts/requirements.txt`; для работы с DOCX дополнительно использовать `scripts/requirements-reports.txt`. `scripts/run_all.cmd` обновляет ноутбуки ПР1 и ПР2; `scripts/start_jupyter.cmd` запускает Jupyter. Отчёты оформляются по [единому справочнику](../../../Оформление_отчётов.md). Временные сборки и визуальную проверку сохранять в корневом `.cache/` репозитория.
