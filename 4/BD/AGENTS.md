# Требования к отчётам ТИАБД

На титульном листе каждого отчёта по ТИАБД указывать **«Кафедра прикладной математики»**. При использовании титульного макета ИСУРО заменять название кафедры из образца на это название. Требование пользователя от 19.10.2026.

Для будущих отчётов по дисциплине «Технологии и инструментарий анализа больших данных» преподаватель — **Приходько Н.А.** Не переносить фамилию преподавателя из образца ИСУРО или старых отчётов. В ПР2 Албахтина титульный лист и PDF исправлены 18.10.2026, в ПР3 — 19.10.2026. При следующем разрешённом редактировании остальных отчётов проверить и исправить их титульные листы и PDF.

При актуализации ПР4 Албахтина также исправлены титульник и PDF. Для повторной
сборки только ПР4 использовать `АлбахтинИВ/Исходники/build_pr4_report.py` после
успешных `АлбахтинИВ/Spark/run_pr4.py` и `verify_pr4_data.py`. Общий файл
`ТИАБД_ПР4_Ответы.md` содержит 30 вопросов практики и 7 вопросов лекции №4.

ПР5–7 Албахтина собираются через `АлбахтинИВ/Исходники/build_ml_reports.py`
после полного запуска и `АлбахтинИВ/ML/verify_results.py`. В исходниках
использовать текущие методички `ml_labs/assignment/`. ПР5 содержит самостоятельный
вариант помимо всех учебных блоков. ПР6 выполняется на полном наборе Dry Bean;
выборка используется только для силуэта. ПР7 требует ColabNotebook согласно
странице 11 методички: подготовленный блокнот и локальный Run All не считать
доказательством облачного выполнения. В ПР6/7 отдельных контрольных вопросов
нет; общие файлы ответов содержат фактические вопросы лекций. Для ПР8 без
методички готовятся только ответы лекции 8.

Фактический облачный Run All ПР7 подтверждён в
`АлбахтинИВ/ML/results/pr7/colab/`. Сохранять раздельные времена VM и Colab;
проверка сопоставляет код всех пяти расчётных ячеек по SHA256 и пересчитывает
облачные test-метрики.
