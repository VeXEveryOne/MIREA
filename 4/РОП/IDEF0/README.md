# IDEF0 для первой практики по РОП

`РОП_Практика_1_AS_IS.nsidef0` — редактируемая модель OmniNotation в формате v4. Открыть через «Открыть» / Ctrl+O в актуальном приложении из `D:\OmniNotation`.

В одном файле находятся контекст A-0 и декомпозиция A0. Переключение — через дерево «Диаграммы» или ссылку A0 под контекстной функцией. Сохранены названия, штампы, ICOM-сопоставления, расположение блоков, маршруты и подписи стрелок. Текстовый исходник дополнительно сохранён в одноимённом TXT; для сохранения геометрии открывать именно `.nsidef0`.

Модель описывает AS IS формирования карточек компьютерных систем ООО «Юкомс»: пять функций, возврат замечаний из A3 в A2, четыре внешних результата, включая сведения об ошибке публикации. Управляющие воздействия представлены рабочими правилами академической модели, а не утверждением о наличии конкретных утверждённых регламентов организации.

`A-0.png` и `A0.png` получены из текущего визуального редактора OmniNotation и вставлены в единый отчёт. При подготовке иллюстраций применено оформление для печати: белый фон, скрытые элементы управления и повторяющиеся подписи границ; коды ICOM и названия стрелок сохранены. Встроенный экспорт изображений в приложении отсутствует.

Проверка готовности модели средствами текущего приложения: ошибок и предупреждений нет. Это проверка реализованного профиля, не подтверждение полного соответствия ISO. Отчёт после замены рисунков отрисован и проверен; 16 страниц.
