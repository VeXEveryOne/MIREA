# Разработка обеспечивающих подсистем

Для каждой практической работы готовятся отчёт DOCX и отдельная презентация PPTX. Основание: «Практическое занятие 1.pdf», раздел «Порядок выполнения задания». Общие правила отчётов — в `../../Оформление_отчётов.md`; требование презентации относится к РОП.

## Практика 1

- `РОП_Единый_отчет_АлбахтинИВ.docx` — отчёт; после исправления BPMN 17 страниц.
- `РОП_Практическая_1_АлбахтинИВ.pptx` — презентация к защите: модели AS IS, проблемы, 22 FR и 12 NFR в сгруппированном виде, сравнение аналогов и выводы.
- `IDEF0/` — исходная редактируемая модель IDEF0 и иллюстрации.
- `BPMN/` — исправленная модель BPMN, два вида и пояснение принятых решений.

Оценки аналогов в презентации перенесены из отчёта и обозначены как авторские экспертные. Оценка проектируемой ИС отражает целевые требования, а не измеренный результат внедрения.

## Практики 1–8

[Комплект по всем восьми практикам](Практики_1-8/README.md) продолжает вариант первой практики: карточки компьютерных систем ООО «Юкомс». Включает единый отчёт DOCX/PDF, восемь презентаций, четыре проекта OmniNotation, черновики остальных схем и модель БД.

[Список 38 рисунков и схем](Практики_1-8/СПИСОК_СХЕМ.md) содержит требования методичек, ссылки и статус каждого файла. [Матрица требований](Практики_1-8/МАТРИЦА_ТРЕБОВАНИЙ.md) показывает покрытие заданий. Новые материалы собраны отдельно; исходные файлы практики 1 сохранены.
