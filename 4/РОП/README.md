# Разработка обеспечивающих подсистем

Актуальные результаты всех восьми практик собраны в [Практики_1-8](Практики_1-8/README.md): единый отчёт, восемь презентаций, редактируемые модели и модель базы данных. Вариант — формирование и актуализация карточек компьютерных систем ООО «Юкомс»; исходные 22 FR и 12 NFR сохранены.

Методички «Практическое занятие 1.pdf» — «Практическое занятие 8.pdf» и учебное пособие находятся в текущем каталоге. Требование отдельных презентаций относится к РОП; оформление отчёта — по [единому справочнику](../../Оформление_отчётов.md).

Начать просмотр с [единого DOCX](Практики_1-8/РОП_Практики_1-8_АлбахтинИВ.docx) или [PDF](Практики_1-8/РОП_Практики_1-8_АлбахтинИВ.pdf). Старый отдельный отчёт первой практики и его копии заменены общим комплектом; данные для воспроизводимой сборки сохранены в `Практики_1-8/Исходники/baseline_tables.json`.
