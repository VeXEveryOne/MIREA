# Сборка комплекта

Исходники рассчитаны на текущую структуру репозиториев `D:/GitHub/MIREA` и `D:/OmniNotation`. Перед переносом настроить пути к репозиториям и библиотекам в начале скриптов. Вызовы Python используют python-docx, pypdf, Pillow и упакованный render_docx.py; Node — artifact-tool, sharp и модули текущего OmniNotation. Для PDF используется установленный Microsoft Word через COM, затем bundled Poppler для проверки страниц.

Порядок при изменении материалов:

1. `schema.py` — модель БД и SQL; `drafts.py` — SVG, JSON и реестр черновиков. `render_svg.mjs` получает PNG для отчёта.
2. `rebuild_process_models.mts` полностью пересобирает IDEF0 AS IS и TO BE; `fix_as_is_bpmn_layout.py` формирует согласованные виды BPMN AS IS. `validate_native.mts` декодирует и проверяет четыре процессных проекта.
3. Пакетный экспорт OmniNotation формирует 38 рисунков в `../Модели_для_отчёта/PNG_final4`. Каноническими считаются проекты из `../Модели_OmniNotation_v2`.
4. `content.py` и `build_report.py` — содержание и единый DOCX. Для сохранения исходных FR/NFR требуется существующий `4/РОП/РОП_Единый_отчет_АлбахтинИВ.docx`. Для титула нужен `4/ИСУРО/ИСУРО_1_АлбахтинИВ.docx`. Эти источники не изменяются.
5. `export_word.ps1` — обновление полей и содержания, экспорт PDF. `render_with_word.py DOCX PDF ПАПКА [DPI]` — растеризация через packaged render_docx.py. После изменений проверить затронутые страницы.
6. `slides.mjs [первая_практика] [последняя_практика]` заново собирает PPTX. Практика 1 содержит 15 слайдов, практика 2 — 10; корневая копия практики 1 синхронизируется автоматически.
7. `sync_final_outputs.py` синхронизирует итоговые имена отчёта, совместимые PNG и реестр 38 рисунков. `package_check.py` выполняет финальную проверку комплекта без изменения исходников.

Новые нотации в OmniNotation не реализовывались. Файлы `*.draft.json` — данные для будущего переноса, а не текущий формат импорта. Для ERD все 185 атрибутов, ключи и межвидовые связи доступны в `../База_данных/model.json`; на картинках показан сокращённый состав для читаемости.

SQL не запускался в PostgreSQL. Проверки комплекта не заменяют испытания будущего приложения, миграций и интеграций.
