# РОП: практики 1–8

Вариант Албахтина И.В.: информационная система формирования и актуализации карточек компьютерных систем ООО «Юкомс». Комплект сохраняет исходные 22 функциональных и 12 нефункциональных требований.

- [Единый отчёт DOCX](РОП_Практики_1-8_АлбахтинИВ.docx), [PDF](РОП_Практики_1-8_АлбахтинИВ.pdf) и [текст Markdown](РОП_Практики_1-8_АлбахтинИВ.md).
- [Презентации](Презентации/) — восемь PPTX, по одному для каждой практики.
- [Список 38 рисунков](СПИСОК_СХЕМ.md) и [матрица требований](МАТРИЦА_ТРЕБОВАНИЙ.md).
- [Модели](Модели/) — 12 актуальных проектов OmniNotation; здесь же реестр рисунков и задание пакетного экспорта.
- [Экспорт/PNG](Экспорт/PNG/) — 38 основных рисунков, восемь продолжений моделей данных и 11 частей двух длинных диаграмм последовательности для отчёта.
- [База данных](База_данных/) — 29 таблиц, 185 атрибутов, модель JSON и заготовка SQL PostgreSQL.
- [Черновики схем](Черновики_схем/) — исходные SVG/JSON для генерации и редактирования схем; это отдельный формат исходных данных.
- [Исходники](Исходники/README.md) — генераторы, сохранённая база FR/NFR и проверки.

Канонические отчёт, модели и иллюстрации существуют в одном экземпляре. Генераторы используют относительные пути и создают временные файлы в `.cache/rop/`. `SHA256.json` содержит контрольные суммы комплекта, а файлы `ПРОВЕРКА*.json` — результаты проверок.

Проектные расчёты и SQL являются учебными материалами. SQL не запускался в PostgreSQL; структуры и ограничения проверены статически.
