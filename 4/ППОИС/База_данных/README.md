# База данных ППОИС 7

`schema.sql` — каноническая физическая модель PostgreSQL; `privileges.sql` —
права четырёх NOLOGIN-ролей; `queries.sql` — шесть функциональных запросов.
Создавать объекты только в отдельной учебной базе. Скрипты не содержат DROP
и не сбрасывают существующий кластер. Пароли и рабочие учётные записи не входят в Git.

`../Исходники/verify_database.py` создаёт отдельную базу с новым именем,
выполняет DDL/DCL, заполняет синтетические тестовые записи и проверяет ограничения
и права. Тестовые цены не являются прайс-листом поставщика. Состояния публикации
проверяются на локальных тестовых записях; исполняемый шлюз и отправка в Ozon
в этом срезе не реализованы.

Слабые сущности имеют составные идентифицирующие ключи: версия BOM, позиция,
ревизия карточки, связь изображения с ревизией и попытка публикации. Изменения состава и экономических значений
оформляются новыми версиями/ревизиями. Приём внешней задачи не означает публикацию.
