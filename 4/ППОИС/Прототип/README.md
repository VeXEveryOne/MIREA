# Исполняемый учебный срез ППОИС

Версия 0.1 читает состав из отдельной PostgreSQL-базы, выбирает свежие предложения
с достаточным остатком, проверяет совместимость и вычисляет цену и массу через
Decimal. Она сравнивает результат с двумя сохранёнными ревизиями карточек.
Внешних запросов и записи в БД нет: внутри транзакции проверяются READ ONLY
и роль `ppois_viewer`. Владельцем схемы подключаются только на локальном учебном
стенде для переключения на ограниченную роль, не в промышленной системе.

## Запуск

Рабочий каталог — корень MIREA. `python` ниже обозначает Python из task-окружения
`.cache/ppois5-10/venv/Scripts/python.exe` с зависимостями `requirements.txt`.
PostgreSQL запускается только локально на `127.0.0.1:55432`; не использовать
рабочую БД или чужой кластер. Проверка создаёт новую учебную базу без DROP.

```powershell
python 4/ППОИС/Исходники/verify_database.py
python 4/ППОИС/Исходники/verify_prototype.py
$ppoisFixture = Get-Content -LiteralPath '4/ППОИС/База_данных/Результаты_проверки.json' -Raw | ConvertFrom-Json
python 4/ППОИС/Прототип/demo.py --database $ppoisFixture.database --configuration 00000000-0000-0000-0000-000000000100 --version 1 --now '2026-10-05T10:00:00+03:00' --evidence .cache/ppois5-10/prototype-demo.json
```

Момент проверки обязателен и имеет часовой пояс. Учебные цены от 5 октября 2026
не объявляются актуальными котировками. При более позднем моменте проверка
возвращает ошибку устаревших предложений. `--evidence` разрешён только внутри
`.cache/`; исходники и секреты не перезаписываются.

На контрольных данных: комплектующие 51 000 руб., себестоимость 53 500 руб.,
продажная цена 76 400 руб., масса с упаковкой 7,820 кг. Проверены 17 доменных
сценариев и четыре сценария исполняемого среза с реальной БД. Прогон сохраняет
результаты и хэши текущих исходников, а не заранее объявленный зелёный статус.

## Границы версии

HTTP-формы, публикация, фоновая очередь, промышленный TLS, нагрузочная проверка
и восстановление пока не реализованы в срезе 0.1. `may_retry` проверяет только
решение о допустимости повтора, но не отправляет запрос. Независимый подбор
по слотам завершается проверкой всей конфигурации; поиск альтернативной
комбинации при конфликте не заявляется.
