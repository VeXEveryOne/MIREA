# Управление технологической компанией

В корне находятся отчёты практик, курсовая работа и общие материалы. Сервисные договоры четвёртой практики хранятся в [4 практика](<4 практика/>); их одинаковые корневые копии убраны. [МЕТОДИЧКИ](МЕТОДИЧКИ/) содержит материалы преподавателя.

Различающиеся версии отчётов сохранены: название с `v2` не считается достаточным основанием для удаления другой версии без проверки содержимого и истории сдачи.
