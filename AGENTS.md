# Оформление учебных отчётов

При создании, редактировании или проверке отчётов по любому предмету сначала прочитать [единый справочник оформления](Оформление_отчётов.md) в корне репозитория и применять его правила. Справочник содержит требования пользователя, дополнительные настройки по образцам и явно обозначенные рекомендации.

Титульный лист брать за основу из `4/ИСУРО/ИСУРО_1_АлбахтинИВ.docx`, используя только его титульную страницу и учитывая исправления реквизитов и скрытого старого текста, описанные в справочнике. Не переносить оформление основной части ИСУРО автоматически.

Явные указания пользователя имеют приоритет. При новых общих требованиях обновлять единый справочник, чтобы правила для предметов не расходились. Предметные исключения отражать в материалах соответствующего предмета. Эта инструкция не требует массово переформатировать существующие отчёты вне текущего задания.
