# Яндекс Практикум

Материалы спринтов находятся в каталогах `sprint5`–`sprint14`; документы с разными номерами этапов сохраняются отдельно. Курсовые отчёты, методические материалы и инструменты обработки находятся в текущем каталоге и `tools/`.

[Playlist Maker](playlist-maker-android-AlbahtinIlya/) — подмодуль с версией проекта для этого этапа курса. Более поздний проект сохранён [в корне MIREA](../playlist-maker-android-AlbahtinIlya/).

`dev/advanced-git/` и `dev/git-advanced-2/` — исходные файлы учебных примеров. Локальные Git-истории этих упражнений сохранены в резервной копии очистки; примеры больше не являются неполными подмодулями родительского репозитория. [vexapp](vexapp/) хранит исходники Android-приложения; кэш Gradle и результаты сборки исключены.
