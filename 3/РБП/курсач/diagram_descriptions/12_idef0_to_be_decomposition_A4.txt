Название диаграммы
IDEF0 to-be. Декомпозиция A4 «Фиксация результатов диагностики».

Где вставляется в отчете
Раздел 4.1, рисунок 4.3.

Назначение
Показать, как после реинжиниринга CMS контролирует заполненность результата диагностики и не позволяет передать заказ дальше при замечаниях или неполных данных.

Элементы
Блоки:
A41 «Получение статуса о передаче на диагностику».
A42 «Внесение или прикрепление результатов диагностических утилит».
A43 «Автоматическая проверка заполненности результата диагностики».
A44 «Блокировка передачи дальше и возврат информации при замечаниях».
A45 «Передача положительного результата на финальный контроль».

Входы слева:
1. Статус передачи на диагностику -> A41.
2. Карточка заказа -> A41, A43.
3. Данные диагностических утилит -> A42.

Управления сверху:
1. Шаблон результата диагностики -> A42.
2. Правила обязательности диагностических полей -> A43.
3. Правила обработки замечаний -> A44.
4. Правила смены статусов -> A41, A45.

Механизмы снизу:
1. Внутренняя CMS -> A41-A45.
2. Инженер тестирования -> A42.
3. AIDA64, FurMark, CrystalDiskInfo/CrystalDiskMark, OCCT -> A42.
4. Руководитель отдела производства -> A44 при контроле возврата.

Выходы справа:
1. Структурированный результат диагностики.
2. Блокировка передачи дальше при замечаниях.
3. Информация на уточнение/устранение причины.
4. Положительный результат, переданный на финальный контроль.

Связи / порядок соединения
1. A41 -> A42: «Заказ принят на диагностику».
2. A42 -> A43: «Результаты диагностики внесены/прикреплены».
3. A43 -> A44: «Есть замечания или обязательные поля не заполнены».
4. A44 -> A42: «Требуется корректировка и повторная фиксация результата».
5. A43 -> A45: «Результат заполнен, замечаний нет».
6. A45 -> внешний выход: «Положительный результат передан на финальный контроль».

Развилки и исключения
После A43:
- если результат заполнен и замечаний нет: A43 -> A45;
- если есть замечания или неполные поля: A43 -> A44 -> возврат к A42.

Что выделить цветом или пометкой
1. A43 и A44 выделить как новые to-be элементы.
2. Стрелку блокировки выделить красным или пометкой «блокировка CMS».
3. A42 отметить как действие инженера, но с использованием шаблона CMS.

Проверка перед вставкой в отчет
1. Есть A41-A45.
2. A43 является автоматической проверкой CMS.
3. При замечаниях нет прямого перехода к финальному контролю.
4. Диагностические утилиты указаны как источник данных.
