Название диаграммы
IDEF0 as-is. Декомпозиция A0.

Где вставляется в отчете
Раздел 2.2, рисунок 2.4.

Назначение
Раскрыть центральный блок A-0 на пять подпроцессов A1-A5 и показать, как между ними движется информация.

Элементы
Блоки внутри диаграммы:
A1 «Принятие и первичная проверка заказа».
A2 «Подготовка информационного задания и данных о комплектующих».
A3 «Информационное сопровождение сборочного этапа».
A4 «Фиксация результатов диагностики».
A5 «Финальный контроль и передача сведений о готовности».

Внешние входы слева:
1. Карточка заказа -> A1.
2. Спецификация конфигурации -> A1.
3. Учетные данные склада -> A2.
4. Статус заказа -> A1.

Управления сверху:
1. Регламент обработки заказа -> A1, A3, A5.
2. Правила проверки состава конфигурации -> A1, A2.
3. Правила фиксации серийных номеров -> A2.
4. Правила смены статусов -> A1, A3, A5.
5. Порядок фиксации результатов диагностики -> A4.

Механизмы снизу:
1. Руководитель отдела производства -> A1, A5.
2. Платформер -> A2, A3.
3. Сборщик ПК -> A3.
4. Инженер тестирования -> A4.
5. Упаковщик -> A5.
6. Внутренняя CMS -> A1-A5.
7. Диагностические утилиты -> A4.

Выходы справа:
1. Обновленная карточка заказа <- A5.
2. Привязанные SN <- A2.
3. Результаты диагностики <- A4.
4. Отметка о готовности <- A5.
5. Сведения, переданные в следующий процесс <- A5.

Связи / порядок соединения
1. Расположить блоки слева направо: A1 -> A2 -> A3 -> A4 -> A5.
2. Из A1 в A2 провести стрелку «Проверенные цена, состав и статус; заказ принят в работу».
3. Из A2 в A3 провести стрелку «Задание исполнителю; данные комплектующих; привязанные SN».
4. Из A3 в A4 провести стрелку «Статус передачи на диагностику; отметки завершения этапов».
5. Из A4 в A5 провести стрелку «Результат диагностики; положительный результат или замечания».
6. Из A5 вправо вывести «Отметка о готовности» и «Сведения, переданные в следующий процесс».
7. Из A4 при наличии замечаний можно провести обратную стрелку к A3 или A2 с подписью «Информация на уточнение/устранение причины». Если на диаграмме слишком тесно, эту стрелку раскрыть на декомпозиции A4.

Развилки и исключения
Главное исключение: если в A4 есть замечания, процесс не должен сразу идти в A5.
В IDEF0 это показывается обратной информационной стрелкой «Замечания / информация на уточнение».

Что выделить цветом или пометкой
Это as-is. Можно выделить A4 как проблемный участок ручного контроля.

Проверка перед вставкой в отчет
1. Есть пять блоков A1-A5.
2. Потоки между блоками информационные.
3. A4 не выглядит как всегда успешный линейный переход.
4. В диаграмме нет физической сборки как отдельного блока.
