Название диаграммы
IDEF0 as-is. Декомпозиция подпроцесса A4 «Фиксация результатов диагностики».

Где вставляется в отчете
Раздел 2.2, рисунок 2.5.

Назначение
Подробно раскрыть проблемный участок диагностики as-is: как фиксируются результаты, что происходит при замечаниях и почему процесс не должен идти дальше без повторной фиксации.

Элементы
Блоки внутри диаграммы:
A41 «Получение статуса о передаче на диагностику».
A42 «Внесение результатов диагностических утилит».
A43 «Фиксация замечаний или положительного результата».
A44 «Возврат информации на уточнение при наличии замечаний».
A45 «Передача положительного результата на финальный контроль».

Входы слева:
1. Статус передачи на диагностику -> A41.
2. Карточка заказа -> A41.
3. Данные диагностических утилит -> A42.

Управления сверху:
1. Порядок фиксации результатов диагностики -> A42, A43.
2. Правила обработки замечаний -> A43, A44.
3. Правила смены статусов -> A41, A45.

Механизмы снизу:
1. Инженер тестирования компьютерной техники -> A42, A43.
2. Внутренняя CMS -> A41-A45.
3. AIDA64, FurMark, CrystalDiskInfo/CrystalDiskMark, OCCT -> A42.
4. Руководитель отдела производства -> A44 при необходимости уточнения.

Выходы справа:
1. Результат диагностики.
2. Запись о замечаниях.
3. Положительный результат диагностики.
4. Информация на уточнение/устранение причины.
5. Результат, переданный на финальный контроль.

Связи / порядок соединения
1. A41 -> A42: «Заказ принят на диагностику».
2. A42 -> A43: «Внесенные результаты диагностики».
3. A43 -> A45: «Положительный результат, замечаний нет».
4. A43 -> A44: «Замечания выявлены».
5. A44 -> A41 или A42: «Информация возвращена на уточнение; требуется повторная фиксация».
6. A45 -> внешний выход справа: «Результат диагностики передан на финальный контроль».

Развилки и исключения
Основная развилка после A43:
- Если замечаний нет: A43 -> A45.
- Если замечания есть: A43 -> A44 -> возврат к повторной фиксации результата.

Что выделить цветом или пометкой
1. A44 выделить как проблемный возврат as-is.
2. Подписать, что возврат зависит от ручной фиксации замечаний.
3. Не показывать физическое тестирование как трудоемкую операцию: на диаграмме фиксируется только информационный результат диагностики.

Проверка перед вставкой в отчет
1. Есть блоки A41-A45.
2. Есть обратная стрелка при замечаниях.
3. Есть выход положительного результата на финальный контроль.
4. Диагностические утилиты указаны как механизм/источник информации, а не как платное ПО.
